# TV Shell — домашний экран для Philips 65PUS8139/60 (Android TV)

Лёгкий лаунчер без рекламы и рекомендаций. Без сторонних библиотек, ~100 КБ.

**Что умеет**
- большие часы и дата;
- **Избранное** — свои приложения в своём порядке (YouTube, Кинопоиск, Okko и т. п.);
- **Источники** — прямое переключение на HDMI 1–4 и эфирное ТВ;
- **Все приложения** — сеткой, с ТВ-баннерами, по алфавиту;
- меню приложения (удерживайте **ОК** или нажмите **☰**): в избранное / сдвинуть / скрыть / о приложении / удалить;
- быстрые кнопки: настройки ТВ, Wi‑Fi, Bluetooth;
- перехват кнопки **«Домой»** и запуск после включения ТВ (по желанию).

## 1. Собрать APK

### Вариант А — через GitHub (без установки чего-либо)
1. Создайте пустой репозиторий на github.com и загрузите в него содержимое этой папки
   (кнопка **Add file → Upload files**, перетащите всё, включая папки `.github`, `gradle`, `keystore`).
2. Откройте вкладку **Actions** — сборка запустится сама (≈3–5 минут).
3. В завершённой сборке внизу, в разделе **Artifacts**, скачайте `TvShell-apk` (zip с `app-release.apk`).

> Папка `.github` скрытая: если загрузчик её не видит, создайте файл
> `.github/workflows/build.yml` вручную через **Add file → Create new file** и вставьте содержимое.

### Вариант Б — Android Studio
Откройте папку проекта, дождитесь синхронизации, **Build → Build APK(s)**.
Или в терминале: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`.

## 2. Установить на телевизор

**Через флешку**
1. Скопируйте `app-release.apk` на флешку, вставьте в ТВ.
2. Установите файловый менеджер из Google Play (например, *File Commander* или *X-plore*), откройте APK.
3. Разрешите этому файловому менеджеру «Установку неизвестных приложений», когда ТВ спросит.

**Через ADB по сети** (удобно для обновлений)
1. Настройки → Настройки устройства → Об устройстве → 7 раз нажмите «Сборка» — включится режим разработчика.
2. Настройки → Настройки устройства → Для разработчиков → включите **Отладку по USB / по сети**.
3. На компьютере: `adb connect <IP-телевизора>` (подтвердите запрос на ТВ), затем `adb install -r app-release.apk`.

Новые версии ставятся поверх старых — избранное сохраняется.

## 3. Сделать оболочку главным экраном

Android TV по кнопке «Домой» всегда открывает свой экран и не даёт выбрать другой. Два способа обойти:

### Способ 1 — служба «Кнопка «Домой»» (без компьютера, рекомендуется)
В оболочке: **Настройки → Кнопка «Домой» → Открыть спец. возможности**,
включите **«TV Shell — кнопка «Домой»»**. После этого:
- кнопка «Домой» на пульте открывает TV Shell;
- после включения телевизора открывается TV Shell.

Служба не читает экран и ничего не отправляет — только ловит одну кнопку.
Если на вашей прошивке службы нет в списке, её можно включить через ADB:
```
adb shell settings put secure enabled_accessibility_services ru.tvshell/ru.tvshell.HomeKeyService
adb shell settings put secure accessibility_enabled 1
```

### Способ 2 — отключить штатный лаунчер через ADB (радикально)
Узнайте, какой лаунчер сейчас главный:
```
adb shell cmd package resolve-activity -a android.intent.action.MAIN -c android.intent.category.HOME
```
Отключите его (пример для Google TV и для обычного Android TV):
```
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
adb shell pm disable-user --user 0 com.google.android.tvlauncher
```
Вернуть обратно:
```
adb shell pm enable com.google.android.apps.tv.launcherx
adb shell pm enable com.google.android.tvlauncher
```
⚠️ Отключение штатного лаунчера может сломать часть функций (голосовой поиск с главного экрана,
некоторые меню Philips, обновления «Каналов»). Начните со способа 1.

## Структура
```
app/src/main/java/ru/tvshell/
  MainActivity.kt    — экран, ряды, меню, источники
  TileView.kt        — плитка с анимацией фокуса
  AppRepository.kt   — список приложений и баннеров
  Prefs.kt           — избранное и скрытые
  HomeKeyService.kt  — перехват кнопки «Домой»
```
Идеи для доработки: погода в шапке, фон-картинка, детский режим с PIN, цвета под Ambilight.
